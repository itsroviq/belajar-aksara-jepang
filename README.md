# Japanese Writing Mastery 🇯🇵

**Belajar menulis aksara Jepang dari nol hingga dasar Kanji.**

Japanese Writing Mastery adalah aplikasi pembelajaran mandiri berbasis web yang dirancang untuk membantu pemula mempelajari sistem penulisan bahasa Jepang secara bertahap, mulai dari persiapan awal hingga pengenalan Kanji.

Aplikasi ini menggunakan pendekatan pembelajaran progresif agar pengguna dapat menyelesaikan materi secara berurutan sebelum melanjutkan ke pelajaran berikutnya.

## ✨ Fitur Utama

- **Pembelajaran bertahap:** Kurikulum Level 0 sampai Level 4.
- **Hiragana:** Mempelajari karakter Hiragana.
- **Katakana:** Mempelajari karakter Katakana.
- **Writing Skills:** Melatih keterampilan menulis.
- **Kanji Fundamentals:** Mengenal dasar-dasar Kanji.
- **Animasi urutan goresan:** Membantu memahami cara penulisan karakter.
- **Sistem kunci pelajaran:** Materi berikutnya terbuka setelah pelajaran sebelumnya diselesaikan.
- **Eksplorasi bebas:** Tersedia pilihan untuk menjelajahi materi tanpa mengikuti urutan.
- **Bookmark:** Menandai karakter yang ingin dipelajari kembali.
- **Pelacakan progres:** Menyimpan perkembangan belajar.
- **Backup & Restore:** Mengekspor dan memulihkan data progres belajar melalui file JSON.
- **Sertifikat penyelesaian:** Membuat sertifikat setelah menyelesaikan kurikulum.

## 📚 Kurikulum Pembelajaran

| Level | Materi |
|---|---|
| Level 0 | Preparation |
| Level 1 | Hiragana |
| Level 2 | Katakana |
| Level 3 | Writing Skills |
| Level 4 | Kanji Fundamentals |

## 🚀 Cara Menggunakan

1. Buka aplikasi melalui GitHub Pages.
2. Mulai dari Level 0.
3. Selesaikan setiap pelajaran untuk membuka pelajaran berikutnya.
4. Gunakan fitur latihan dan animasi untuk membantu proses belajar.
5. Pantau progres melalui dashboard.
6. Lakukan backup progres secara berkala.


## 💾 Penyimpanan Data

Aplikasi menggunakan `localStorage` pada browser untuk menyimpan progres belajar.

Perlu diperhatikan:
- Data tersimpan secara lokal di browser dan perangkat yang digunakan.
- Progres tidak otomatis tersinkronisasi antarperangkat.
- Gunakan fitur Backup untuk menyimpan cadangan progres.
- Gunakan Restore untuk memulihkan progres dari file cadangan.
